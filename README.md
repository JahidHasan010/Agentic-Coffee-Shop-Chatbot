# AI Meets Coffee: A Multi-Agent Chatbot Revolution for Coffee Shops! 🤖

## Overview

This project showcases an intelligent coffee shop chatbot, powered by a 5-agent multi-AI system, built entirely in Pure Python. It aims to provide a personalized and seamless interaction experience for coffee shop customers.

## Key Features

* **Multi-Agent Architecture:**
    * **Gatekeeper Agent:** Filters and validates user queries using Pinecone embeddings.
    * **Query Classifier:** Uses Gemini API for intent detection and smart routing.
    * **Specialized Agents:**
        * **Food Recommender:** Suggests ideal food and drink combinations using Market Basket Analysis.
        * **Menu Expert:** Provides real-time, accurate menu details using Retrieval-Augmented Generation (RAG).
        * **Order Manager:** Facilitates smooth and natural ordering conversations.
    * **Context Manager:** Maintains user memory for seamless interaction.
* **AI Tech Stack:**
    * **Pinecone:** For lightning-fast vector search of menu insights.
    * **Gemini API:** For LLM-powered understanding and human-like responses.
    * **RAG (Retrieval-Augmented Generation):** To ensure up-to-date and factually accurate answers.
    * **Gradio:** For an interactive café-style chatbot interface.
    * **Market Basket Analysis:** To provide "Customers who ordered X also liked Y..." recommendations.
* **Prompt Engineering Techniques:**
    * Few-Shot Prompting
    * Chain-of-Thought (CoT) Prompting
    * Dynamic Prompt Injection
    * Persona-Based Prompting
